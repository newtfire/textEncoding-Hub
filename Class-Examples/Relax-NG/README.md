# Relax NG Compact Syntax

* Read our [Relax NG Tutorial](https://newtfire.org/courses/tutorials/explainRNG.html)
* Examples of Relax NG schema development are here!
* Files are saved with .rnc extension.
* How to split your screen in oXygen to edit while viewing your XML file:
    * Window >> Tile Editors Vertically 
    * (or use the Tile Editors Horizontally if you prefer top / bottom tiling).
* To associate your schema with your XML file: In oXygen go to Document >> Schema >> Associate Schema, and navigate to your schema file.
